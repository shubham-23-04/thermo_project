Theory behind the simulator

Model equation and interpretation

P = RT / (V − b) − a(T) / [(V + εb)(V + σb)]
What the parameters represent

The parameter b represents excluded molecular volume. The attraction parameter a(T) describes intermolecular attractions and changes with temperature for RK, SRK and PR.

What this simulator emphasises

Instead of calculating total enthalpy and entropy, this version focuses on pressure sweeps, fugacity-based phase stability, saturation pressure and P–V behaviour.

Method: the cubic equation in compressibility factor is solved numerically/analytically for admissible roots Z > B, where B = bP/(RT). The smallest and largest roots are treated as liquid-like and vapour-like, respectively. The stable root is selected using the lower residual Gibbs energy criterion, represented by ln φ.

Educational simulator for pure-component real-gas behaviour. All calculations run inside this HTML file; no external libraries, server or internet connection is needed. Not intended for process-design decisions.
